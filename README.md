# Calculadora de Expresiones Matemáticas

## Descripción
API REST que convierte expresiones matemáticas de notación **infix** (normal) a **postfix** (notación polaca inversa) y las resuelve.

## Tecnologías
- Java 17
- Spring Boot 3.5.14
- Maven

## Cómo probar

### Requisitos
- Tener Java instalado
- Tener curl o Postman

### Ejecutar
```bash
./mvnw spring-boot:run
